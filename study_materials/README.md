# Inception — Study Materials

This folder contains everything you need to understand, defend, and operate this project.

| File | Purpose |
|---|---|
| [`EVALUATION_QA.md`](./EVALUATION_QA.md) | **Start here.** Mirrors the official evaluation sheet section-by-section. Every question an evaluator can ask, with full theoretical answers and demo commands. |
| [`IMPLEMENTATION.md`](./IMPLEMENTATION.md) | Per-service deep dive: every Dockerfile, config file, and entrypoint script explained line-by-line. |
| [`ARCHITECTURE.md`](./ARCHITECTURE.md) | System architecture diagrams, inter-service communication matrix, Docker networking internals, volume and secrets maps. |
| [`DOCKER_CHEAT_SHEET.md`](./DOCKER_CHEAT_SHEET.md) | Quick reference for all commands you'll actually use during evaluation and day-to-day work. |

## Recommended Reading Order

1. **EVALUATION_QA.md** — understand what you'll be asked and why
2. **ARCHITECTURE.md** — visualize how all pieces connect
3. **IMPLEMENTATION.md** — understand what every line of code does
4. **DOCKER_CHEAT_SHEET.md** — memorize the commands for live demos
